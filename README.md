# Number guessing game

Простая консольная игра, где пользователю нужно отгадать число от *1* до *100*.

---

## Описание проекта

Компьютер загадывает случайное число от **1 до 100**. Задача игрока - ввести свой вариант ответа. После каждой попытки программа дает подсказку:
* число **больше** загаданного
* число **меньше** загаданного

Игра продолжается до тех пор, пока пользователь не угадает число. В конце выводится статистика: **затраченное время,** **общее количество попыток,** **оценка эффективности** игрока на основе количества попыток.

---

## Система оценок

Ваш результат оценивается по следующей шкале (чем меньше попыток, тем выше балл):

* **🥇 Отлично (5 звезд)** — угадали за 1–7 попыток (Идеальная стратегия бинарного поиска!).
* **🥈 Хорошо (4 звезды)** — угадали за 8-10 попыток (Отличный результат).
* **🥉 Удовлетворительно (3 звезды)** — угадали за 11-12 попыток (Нормально, но можно быстрее).
* **Попробуйте еще раз** — более 12 попыток (Вам явно не везло, попробуйте [бинарный поиск](https://habr.com/ru/articles/783848/)!).

```text

Я загадал число от 1 до 100. Попробуйте его угадать!

Введите ваше число: 50
Мое число МЕНЬШЕ.

Введите вашу попытку: 25
Мое число БОЛЬШЕ.

Введите вашу попытку: 37
Поздравляю! Вы угадали число 37!
Количество попыток: 3
Затраченное время: 23 секунды
Ваша оценка: 🥇 Отлично (5 звезд)!
```
