# Number guessing game

Простая консольная игра, где пользователю нужно отгадать число в заданном диапазоне.

---

## Описание проекта

Пользователь задает желаемый диапазон. 
Компьютер загадывает случайное число **в заданном диапазоне**. Задача игрока - ввести свой вариант ответа. После каждой попытки программа дает подсказку:
* Ваше число **больше** загаданного
* Ваше число **меньше** загаданного

Игровая сессия продолжается до тех пор, пока пользователь не угадает число. 
В конце выводится статистика: **общее количество попыток,** **затраченное время,**  **оценка эффективности**  игрока на основе количества попыток, полученное количество **очков,** зависящее от выбранного диапазона. 
После игры предлагается перейти к **призам.** Призы - **картинки** собранные из символов. При достаточном количестве очков, в консоли появится выбранный приз. При желании, можно повторно перейти к призам.
После чего предлагается **повторная** игра. Очки суммируются от игры к игре.
